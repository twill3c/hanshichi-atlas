# hanshichi-atlas — 半七アトラス

青空文庫に収録された岡本綺堂『半七捕物帳』全 69 話を、**一話の中に二つの時間が同居している**
という一点から俯瞰する静的 Web アプリ。

半七物はすべて聞き書きの形をとる。明治の「わたし」が老いた半七を訪ね、半七が江戸の事件を語る。
各話には「語る現在(明治)」と「語られる過去(江戸)」があり、本文はその両方に元号を書く。

## いまの状態

L3(年表とリーダー)まで。**画面が出る。**まだデプロイしていない。

```bash
python -m pipeline.build_web            # web/data/ を作る
python -m http.server -d web            # http://localhost:8000/
python harness/inspect_web.py           # 実ブラウザ検品(3 つの幅)
python harness/inspect_web.py --control # 検品器自身が発火するか
```

- `web/index.html` — 年表。同じ目盛りの上に江戸の事件と明治の語りを並べ、
  下に半七の生涯を敷いた。点をたどるとその話を読める。連載順 / 事件年代順で並べ替わる表つき
- `web/map.html` — 捜査圏。本文の地名を外部辞書で同定して配置した図(下敷きの地図は無い)
- `web/reader.html?w=01` — ルビ表示付き本文。ルビは切って読める

## 捜査圏(L4 の実測)

外部の地名辞書(Wikidata の東京都・神奈川県、12,602 件)を本文に当て、**出てきた 320 語を全数目視した**。

| | |
|---|---|
| 地図に置けた地名 | 186 件 / 延べ 2,045 回。うち 88% が半径 2〜3km の核に集まる |
| 地名として採らなかった見出し語 | 87 件。すべてに理由を書いてある |
| 座標を一つに決められなかった地名 | 47 件 |
| 辞書に無い地名 | 8 件。**半七の家である神田三河町がここに入る** |

素通しの照合は使えない。実測で出た誤検出:

- **純粋な部分文字列** —— 追憶 / 大南(大南風) / 戸越(雨戸越し) / 春日(小春日和) /
  六町(五、六町) / 常盤(常盤津) / 関口(玄関口) / 草屋(煙草屋) / 千歳(三千歳)
- **人名** —— 山田 / 石田 / 高木 / 小山 / 宮坂 / 本多 / 三沢
- **座標そのものが誤る** —— 長崎(本文は肥前、辞書は豊島区長崎) / 柳原(本文は神田柳原、
  辞書は足立区柳原で約 6km ずれる) / 白河(本文は奥州)

同名の地物が離れて複数あるときは**編者が選ばない**。新宿は内藤新宿と葛飾区新宿が
約 10km 離れているので、未同定として残してある。

## 事件年(L2 の実測)

69 話を三つに分けた。**推定で埋めた欄は一つも無い。**

| 分類 | 話数 | |
|---|---|---|
| 半七の事件 | 61 | 事件年は 1841–1867。1840 年代 8 / 1850 年代 26 / 1860 年代 33 |
| 半七以前の聞き伝え | 5 | 18・24・33・65・69。半七の生年(1823)より前に置かれた事件 |
| 確定できない | 3 | 05・06・43。本文に年の手がかりが無い |

**半七の生年が事件年を選り分けた。**「半七の事件の年は初陣(1841)以降」という不等式を
掛けると 5 話が引っかかり、読み返すといずれも半七の探索ではなかった。
69「白蝶怪」は最長の一編だが、事件は文化九年(1812)で、動くのは半七の親分・吉五郎の世代である。

一話に事件が二つある話(10・34・39)、本文自身が年を決めかねている話
(17「文久三年か元治元年」)、精度を放棄している話(38「なんでも安政の末年でしたろう」)は、
そのまま複数値・不確実として持つ。

### 話どうしが互いを検算する

69 話は互いを題名で参照する(22 箇所)。参照と同じ文の中に年の主張があるものを
参照先の事件年と突き合わせると、**4 件すべて一致する**。

- 54→51「その翌年の四月……かの『大森の鶏』の一件」→ 1850+1 = 1851 ✓
- 59→40「現に去年の三月、半七が『異人の首』の捕物で横浜へ出張った時に」→ 1862−1 = 1861 ✓
- 64→50「この年の四月、半七はかの『正雪の絵馬』の探索に取りかかっていた」→ 1854 ✓
- 59→55「いつぞや『かむろ蛇』のお話のときに、安政五年のコロリのことを」→ 1858 ✓

### 見つかった食い違いは一つ

47「金の蝋燭」と 63「川越次郎兵衛」は同じ御金蔵破りを書く。犯人も盗まれた額も同じだが、
日付が違う。

- 47 —— 「安政二年**二月**六日の晩に、藤岡藤十郎、野州無宿の富蔵、この二人が共謀して」
- 63 —— 「あの一件は安政二年**三月**六日の夜のことで、藤岡藤十郎と野州無宿の富蔵が共謀して」

年は合っていて、月だけが食い違う。どちらも綺堂が本文に書いた日付なので、
こちらの判定が入る余地は無い。

## 分かったこと

**綺堂の年代表記は内部で破綻していない。**

- 本文が元号年と干支の両方を書いている 6 箇所は、**6 件とも一致する**。
  換算表を 1 年ずらすと 6 件すべてが落ちるので、この照合は素通しではない。
- 半七の生年は、三つの独立な言明がいずれも **文政六年(1823)** に収束する
  (02 の 19 歳・47 の 33 歳・01 の 73 歳)。

当初の目玉「半七の生年は本文の中で矛盾する」は**取り下げた**。根拠にしていた
01「わたしが丁度二十歳の時だから、元治元年」は半七の台詞ではなく、語り手の叔父の台詞だった
(本文は直後に「と、おじさんは先ず冒頭を置いた」と書いている)。経緯は SPEC.md §1 に残してある。

拾えた珍しい表記:

- **慶安二二**(50「正雪の絵馬」)—— 四(死)を忌んで「二二」と書いた絵馬の落款。
  本文が自ら「慶安二二は即ち慶安四年で」と解説している
- **嘉永庚戌**(35「半七先生」)—— 年の字を伴わない干支だけの落款

## 踏んだ罠

- **保存で改行が膨らむ** —— `Path.write_text` を `newline` 指定なしで呼ぶと、Windows では
  原文の CRLF が CR+CRLF になる。全 69 話がそうなっていた。読み戻すと改行が二重になるが、
  下流で「改行が二つ並んだら畳む」という対症療法を書いていたため、症状だけが消えて
  原因が見えなくなっていた。保存物のバイト列そのものを検査する回帰テストを置いた(T-105)
- **元号の換算を改元日の西暦でやると 1 年ずれる** —— 安政への改元は嘉永七年十一月二十七日
  (1855-01-15)だが、嘉永七年 = 安政元年であり、その年の大半は 1854 年である
- **中見出しは当てにならない** —— `h4` で節を切っているのは 69 話中 16 話だけ。
  残り 53 話は節番号が素のテキストで置かれている
